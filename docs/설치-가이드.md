# Chromebook 설치 및 실행 가이드

> 핵심: **다운로드**(파일을 받는 것)와 **설치**(Android 앱으로 등록하는 것)는 다른 단계입니다.
> APK를 받는 것은 대부분 가능하지만, 설치는 Chromebook이 Android 앱을 허용할 때만 됩니다.

## 0단계 — 내 Chromebook이 설치할 수 있는지 먼저 확인

1. 화면 오른쪽 아래 시계 → ⚙ **설정** → **앱** 으로 갑니다.
2. 다음 표에서 내 상황을 찾습니다.

| 설정 → 앱 화면 | 의미 | 할 수 있는 것 |
|---|---|---|
| **Google Play 스토어** 항목이 있고 "켜짐" | Android 앱 실행 가능 | 1단계로. 단, Play 밖의 APK 설치는 아래 방법 B가 필요 |
| Google Play 스토어 항목이 **없음** 또는 "관리자가 사용 중지" | Android 런타임이 꺼져 있음 | **이 Chromebook에서는 APK를 실행할 수 없습니다.** → [설치 차단 시 대안](설치-차단-시-대안.md) |
| 설정 → 고급 → 개발자 → **Linux 개발 환경**이 "사용 불가" | ADB 사이드로딩 불가 | Play 스토어 배포나 관리자 배포 외에는 설치 방법이 없습니다 |

학교·회사에서 관리하는 기기라면 이 설정들은 관리자 정책이 정합니다. 정책을 바꾸거나 우회하려 하지 마세요.

## 1단계 — APK 받기 (다운로드)

방법 ①: 도우미 파일 사용 (파일 앱에서 클릭)
1. [최신 릴리스](https://github.com/lejiyo09/topsecret/releases/latest)에서 `IndependentBrowser-Launcher.html`을 받습니다.
2. **파일** 앱 → 다운로드 폴더에서 이 파일을 클릭하면 Chrome으로 열립니다. *(이 페이지는 도우미일 뿐 브라우저가 아닙니다.)*
3. **APK 다운로드** 버튼을 누릅니다. 파일이 다운로드 폴더에 저장될 뿐 자동 설치되지는 않습니다.

방법 ②: 직접 링크
- https://github.com/lejiyo09/topsecret/releases/latest/download/IndependentBrowser.apk

받은 파일 확인(선택): 릴리스 페이지의 `SHA256SUMS.txt`에 적힌 값과 파일의 SHA-256이 같아야 합니다.

Chrome이 "이 파일은 위험할 수 있습니다" 경고를 보이면, 출처가 위 GitHub 릴리스인지 확인한 뒤 **유지**를 누를 수 있습니다. 관리자 정책으로 다운로드가 막히면 그대로 두세요.

## 2단계 — 설치

### 방법 A. 관리자 배포 (학교·회사 기기에서 유일하게 권장되는 방법)
관리자에게 다음을 요청합니다: "Android 앱 허용 + 이 APK(또는 관리형 Google Play 비공개 앱) 배포". 승인되면 앱이 자동 설치됩니다.

### 방법 B. ADB 사이드로딩 (개인 Chromebook, Linux 사용 가능할 때)
Google 공식 절차(Chrome 81+, 개발자 모드 불필요):
1. 설정 → 고급 → 개발자 → **Linux 개발 환경** 켜기
2. Linux 설정 → **Android 앱 개발** → **ADB 디버깅 사용** 켜기 → 재시작
3. 다운로드 폴더를 Linux와 공유(파일 앱에서 다운로드 폴더 우클릭 → "Linux와 공유")
4. 터미널에서:
   ```bash
   sudo apt install -y adb
   ```
   ```bash
   adb connect arc
   ```
   ```bash
   adb install /mnt/chromeos/MyFiles/Downloads/IndependentBrowser.apk
   ```
5. Chromebook에 "USB 디버깅 허용" 창이 뜨면 허용합니다.

> 사용자 환경(Linux 사용 불가)에서는 방법 B를 쓸 수 없습니다.

### 방법 C. Android 휴대폰·태블릿
APK를 열고 "알 수 없는 앱 설치"를 이 출처에 한해 허용하면 설치됩니다. 데이터 분리 원리는 Chromebook과 같습니다.

## 3단계 — 실행

| 방법 | 설명 |
|---|---|
| 런처 | 키보드의 🔍(런처) 키 → "독립 브라우저" 검색 → 클릭. 선반에 고정하면 다음부터 한 번 클릭 |
| 파일 앱에서 `.html` 클릭 | 파일 우클릭 → **연결 프로그램** → **독립 브라우저** (앱 설치 후 표시됨) |
| 도우미 페이지 | `IndependentBrowser-Launcher.html` → **독립 브라우저 열기** 버튼 → ChromeOS 확인 창에서 열기 |

## 4단계 — 직접 확인할 점검표 (실제 Chromebook에서)

CI는 Android 에뮬레이터(Android 11·14)에서 테스트하며, **실제 Chromebook에서의 설치·실행은 자동으로 검증할 수 없습니다.** 설치에 성공했다면 아래를 확인하세요.

- [ ] 앱이 큰 창(최대화)으로 열리고 창 크기를 바꿔도 탭이 유지된다
- [ ] 주소창에 `example.com` 입력 → Enter → 페이지가 열린다
- [ ] Chrome에서 로그인된 사이트를 이 앱에서 열면 **로그아웃 상태**로 보인다 (쿠키 분리 확인)
- [ ] 이 앱에서 방문한 페이지가 Chrome의 방문 기록(Ctrl+H)에 **나타나지 않는다**
- [ ] Ctrl+T / Ctrl+W / Ctrl+Tab / Ctrl+L / Alt+← 단축키가 동작한다
- [ ] 링크에서 마우스 오른쪽 버튼 → "새 탭에서 열기"가 동작한다
- [ ] 파일을 받으면 확인 창이 뜨고, 파일 앱의 다운로드 폴더에 저장된다
- [ ] 메뉴 → 인터넷 사용 기록 삭제 후 로그인이 해제된다

## 앱 기능 요약

- 주소창(URL·검색어 자동 구분, 검색 엔진: Google/DuckDuckGo/Bing/네이버), 뒤로·앞으로·새로고침·홈
- 여러 탭(탭 줄, 닫은 탭 다시 열기, 앱 재시작 시 탭 복원), 팝업은 클릭으로 연 경우만 허용
- 북마크, 방문 기록(검색·개별 삭제·전체 삭제)
- 인터넷 사용 기록 삭제: 방문 기록 / 쿠키·사이트 데이터(로그인 세션) / 캐시 / 양식 데이터, "다시 시작할 때 모두 삭제" 옵션
- 인증서 오류 사이트는 항상 차단(우회 버튼 없음), 혼합 콘텐츠 차단, Safe Browsing, 파일·콘텐츠 URI 접근 차단
- 다운로드: 파일명·크기·출처·위험 확장자·HTTP 경고를 보여 주고 확인 후 다운로드 폴더에 저장
- 외부 앱 링크(mailto:, intent: 등)는 클릭 + 확인 후에만 열림
- 키보드: 단축키 전체 목록은 앱 메뉴 → "정보 및 단축키"
- 데이터는 Android 앱 전용 저장소에만 있고 클라우드 백업에서도 제외됨
