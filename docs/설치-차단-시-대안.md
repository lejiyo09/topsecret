# APK 설치가 차단되었을 때의 대안

Play 스토어도, Linux 개발 환경도 쓸 수 없는 Chromebook에는 **이 앱을 설치할 방법이 없습니다.**
이 문서는 정책을 우회하지 않고 쓸 수 있는 방법만 정리합니다. 각 방법이 무엇을 분리하고 무엇을 분리하지 못하는지 함께 적었습니다.

## 1. ChromeOS에 이미 있는 분리 기능 (설치 불필요)

| 방법 | Chrome 일반 창과 분리되는 것 | 한계 | 관리 기기에서 |
|---|---|---|---|
| **게스트 모드** (로그인 화면 → "게스트로 탐색") | 방문 기록·쿠키·캐시·로그인 모두. 로그아웃 시 전부 삭제 | 세션이 유지되지 않음(매번 다시 로그인) | 관리자가 끌 수 있음 |
| **별도 ChromeOS 사용자 추가** (로그인 화면 → 사용자 추가) | 기록·쿠키·캐시·로그인 세션·파일까지 완전 분리, **세션 유지됨** | 계정 전환 필요 | 관리자가 허용한 계정만 가능 |
| **Chrome 프로필 추가** (Chrome 오른쪽 위 프로필 아이콘 → 추가) | 기록·쿠키·캐시·로그인 세션 분리, 세션 유지 | 지원 여부는 ChromeOS 버전·정책에 따라 다름 | 관리자가 제한할 수 있음 |
| **시크릿 창** (Ctrl+Shift+N) | 창을 닫으면 그 창의 기록·쿠키 삭제, 일반 창 쿠키와 분리 | 세션 유지 안 됨. 열려 있는 시크릿 창끼리는 쿠키 공유 | 관리자가 끌 수 있음 |

"독립적인 로그인 세션 + Chrome 기록과 분리 + 세션 유지"라는 목표에 가장 가까운 것은 **별도 ChromeOS 사용자** 또는 **Chrome 프로필**입니다.

## 2. 관리자에게 요청 (승인된 정식 경로)

학교·회사 기기라면 관리자에게 아래 중 하나를 요청할 수 있습니다. 요청서에 이 저장소의 `docs/기술-선택-보고서.md`를 첨부하면 앱이 무엇을 하고 무엇을 하지 않는지 설명이 됩니다.

1. **Android 앱 허용 + 앱 배포** — 관리 콘솔에서 Android 앱을 켜고, 이 APK를 관리형 Google Play 비공개 앱으로 등록하거나 사이드로딩을 허용
2. **게스트 모드 / 시크릿 모드 / 다중 프로필 허용**
3. **Linux 개발 환경 허용** (수업 목적 등 정당한 이유가 있을 때)

## 3. 다른 기기 사용

- **개인 Chromebook**: Linux 개발 환경을 켜고 [설치 가이드](설치-가이드.md)의 방법 B로 설치
- **Android 휴대폰·태블릿**: APK를 바로 설치 가능

## 하지 않는 것

다음은 요구사항(학교 정책 우회 금지)에 따라 제공하지 않습니다.

- 개발자 모드 강제 전환, 기기 등록 해제, 관리 정책 해제 방법
- 원격 브라우저·프록시·VPN으로 학교 네트워크 필터를 피하는 방법
- "브라우저처럼 보이는 HTML 페이지" — Chrome 안에서 동작하므로 기록·쿠키가 분리되지 않아 목표를 달성하지 못합니다

## 어떤 방법을 쓰든 남는 기록

- 웹사이트·서비스가 자체 서버에 저장하는 기록(예: Google 계정 '내 활동')
- 학교·회사 네트워크와 관리자 콘솔, 인터넷 사업자의 접속 기록

이 기록들은 브라우저 종류와 상관없이 남으며, 이 앱이나 위 방법들로 삭제·차단할 수 없습니다.
